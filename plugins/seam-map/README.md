# AOD_SeamMap（旧独立版・互換性用）

新規利用には[AOD_SeamScaleの入力マップ機能](../seam-scale/LAYER_MAP.md)を使用してください。v0.3.0で操作を統合し、アンカーから同じ距離なら同じ倍率になるMin/Max方式へ変更しています。この独立版は従来の黒・白補間を必要とする既存プロジェクト用に残しています。

グレースケールの入力レイヤーでシーム変形の倍率を制御し、指定した明るさの位置を固定する独立エフェクトです。

AE 2025への配置と8/16/32bpcの実機検証が完了しました。アンカーによる位置補正を含む試作版です。[検証結果・性能](VALIDATION.md)を参照してください。

## 使い方

1. 変形する画像に `AOD_SeamMap` を適用します。
2. `Scale Map Layer` で制御用のレイヤーを選びます。未指定なら入力画像をそのまま返します。
3. `Black Scale` と `White Scale` に黒・白での倍率を指定します。中間の明るさは直線補間します。
4. `Anchor Map Value` で元の位置に固定する明るさを指定します。

たとえば黒50%、白150%、アンカー30%の場合、明るさ30%でシーム計算に指定する倍率は80%です。アンカーはこの倍率を100%へ変更せず、その場所の位置を固定するための補正に使います。

## パラメーター

| 名前 | 内容 |
|---|---|
| Scale Map Layer | 入力マップ。入力画像と同じピクセル座標で参照します。サイズ合わせが必要な場合は同じサイズでプリコンポーズします。 |
| Map Channel | マップに使うLightness / R / G / B / A。0〜1へ制限します。Lightnessは `0.2126 R + 0.7152 G + 0.0722 B`、透明部分はAEからの乗算済みRGBで扱います。 |
| Separate X/Y Scale | OFFで共通倍率、ONでX/Yそれぞれの黒・白倍率を指定します。 |
| Black / White Scale | -400〜400%。負の値は絶対値の倍率でシーム計算し、その軸を反転します。0%は計算上1ピクセルです。 |
| Anchor Map Value | 固定する明るさ。0%=黒、50%=中間グレー、100%=白。倍率の直線補間には影響しません。 |
| Anchor Tolerance | 指定した明るさの前後を固定対象に含める幅。既定±0.2%で、8bitの中間グレーの量子化差を吸収します。 |
| Seam Channel | シームのエネルギーを計算するチャンネル。RGBAは既存SeamScaleと同じLightness＋Alphaです。 |
| Restore Original Size | 各軸のシーム変形を元サイズへ単純リサイズしてから、アンカーの位置補正を行います。OFFでは中央配置した変形を使います。 |

## アンカーと変形の定義

- 元の座標にあるマップを、X・Y両方の処理で参照します。マップ自体は変形しません。
- 各画素の明るさから倍率を直線補間し、整数ピクセルのサイズへ丸めます。
- 逐次DPで各サイズのシームを正確に求め、その結果から元画像の参照座標を得ます。同じ方向の複数サイズではシーム計算を共有します。低解像度化やシームの近似選択は使いません。
- 行ごとに、指定した明るさの画素と、その明るさをまたぐ画素間の位置をアンカーにします。アンカーが1点なら位置補正量は行内で共通です。複数点なら補正量を区間ごとに線形補間し、外側は端の補正量を使います。その行にアンカーがなければ位置補正しません。
- 補正した座標から入力画像を双線形参照します。画像外は透明です。アンカー許容幅内の画素は元の画素をそのまま保持します。
- Xを処理後、Yを同じ方法で処理します。出力キャンバスは元サイズを維持します。

**固定点の位置と、任意の局所倍率を同時に厳密に満たせるとは限りません。** 黒〜白の倍率設定と補間は保持しますが、複数アンカーの間では位置補正によって最終的な局所倍率が変化します。全画素がアンカー対象なら全画素が元のままになります。急なマップ変化や強い倍率では、変形の不連続・折り返しが生じる場合があります。

この出力は、DPで求めた参照座標に固定点の制約を加える空間変形です。通常のSeamScaleの画素削除・挿入結果そのものとは、特に補間部分で見た目が異なります。計算の高速化のためにシームを近似する方式ではありません。

## ビルド・検証

```powershell
cargo build --release -p seam_map
cargo test -p utils -p seam_map -p seam_scale
cargo run -p utils --release --example seam_map_preview -- target/seam-map-development/preview
```

通常の `just build` はインストールも行うため、作業中のAEへ配置する前にタイミングの確認が必要です。試作版のビルドには上記のcargoコマンドを使います。

共通のDP実装は `crates/utils/src/seam/` にあります。既存SeamScaleも同じ実装を参照します。
