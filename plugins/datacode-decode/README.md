# datacode-decode ( AOD_DatacodeDecode )

Decodes 1D and 2D data codes from layers with auto or region-based detection.

This is the After Effects plugin **AOD_DatacodeDecode**, which provides the **DatacodeDecode.aex** plugin file for Adobe After Effects.
