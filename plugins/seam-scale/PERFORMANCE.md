# AOD_SeamScale v0.1.4 性能検証

この記録はv0.1.4の結果です。最新v0.1.5の配置状況と4K比較は[4K性能検証記録](PERFORMANCE_4K.md)を参照してください。

2026-10-14、Windows、Intel Core i9-14900KF、AVX2。ブランチは`feat/seam-scale`です。

v0.1.3と同じ倍精度DP・加算順序・左優先の同点処理を維持し、AVX2の経路記録と命令の組み合わせを改善しました。GPU、近似シーム、解像度の間引き、前フレームの流用は追加していません。縮小・拡大の両方が使うDP処理が対象です。AVX2非対応CPUの処理は変更していません。

## AE 2025での結果

After Effects 25.6.6x4。ユーザーによる作業保存・終了後にバックアップと差し替えを行い、Computer Useで起動・描画・パラメーター・Render Timeを確認しました。今回はAE MCP経由のテスト実行も成功しています。

前回と同じ1920×1080の合成動画（グラデーションと動く12本の図形）、8bpc、共通倍率50%、RGBA、元サイズ復元OFF、フル解像度です。

| 指標 | v0.1.3 | v0.1.4 |
| --- | ---: | ---: |
| レイヤーのRender Time表示（先頭フレーム） | 約1.05秒 | 0.800秒 |
| 異なる3フレームのPNG書き出し合計 | 3.640秒 | 3.007秒 |
| PNG書き出し込みの平均 | 約1.213秒/フレーム | 約1.002秒/フレーム |

表示した1フレームのRender Timeは約24%、書き出し込みの平均は約17%短縮しています。PNG計測には入力素材の描画・キュー処理・PNGエンコードも含みます。AE内の計測は各版1回ずつ、異なる時点での実行です。ユーザーの実動画や最初の8.56秒の測定とは異なる素材であり、実動画での速度やリアルタイム処理を保証する値ではありません。

出力は前回と同じ`PNG seq (untone-map)`、RGB＋Alpha、16bit PNG、リサイズなしです。3枚とも1920×1080、画像領域は中央の960×540でした。前回の3枚と、IHDRおよび展開後のIDATバイト列が完全一致しています。PNGの16bit値を8bitへ落として比較したものではありません。

8/16/32bpcの描画テスト156ケースもすべて成功し、旧版の156枚と同じ方法で完全一致を確認しました。共通／個別倍率、7チャンネル、拡大、縮小、反転、元サイズ復元、ROI、マスク、半解像度、0%を含みます。今回の変更で描画結果は変わらないため、v0.1.3で作成したカタログ画像を維持しています。

テスト初回はMCPの評価環境で`$.fileName`がブリッジ側を指し、出力先を解決できず失敗しました。`AOD_SEAM_TEST_ROOT`で作業フォルダーを明示し、出力先・ログの検証を追加して再実行しました。プラグインの読み込みエラーは発生していません。

## CLIでの比較

Rust 1.97.1、最適化レベル3。変更前の`seam.rs`と`linked.rs`を保存し、新旧の処理を同じ比較プログラムへ組み込みました。1920×1080から960×540、既定RGBAで各3回、実行順を交互にして比較した中央値です。画像の準備は計測外で、AEの入出力やPNG書き出しは含みません。

| 入力 | v0.1.3 | v0.1.4 | 処理時間の短縮 |
| --- | ---: | ---: | ---: |
| 単色 | 0.164秒 | 0.162秒 | 約1% |
| グラデーション | 1.900秒 | 1.323秒 | 約30% |
| 図形＋グラデーション | 1.564秒 | 0.955秒 | 約39% |
| ノイズ | 1.750秒 | 1.192秒 | 約32% |

12回すべてで出力画素が完全一致しました。単色は既存の局所更新処理が主体のため、今回の全体DPの改善はほぼ影響しません。画像内容や縮小量により改善幅は変わります。

比較ソース・旧版ソース・CSVは`target/seam-scale-perf-0.1.4/`にあります。

```powershell
rustc --edition 2024 -C opt-level=3 target/seam-scale-perf-0.1.4/compare.rs -o target/seam-scale-perf-0.1.4/compare.exe
target/seam-scale-perf-0.1.4/compare.exe 3
```

通常の性能テストは`cargo test -p seam_scale --release benchmark_video_1080 -- --ignored --nocapture`です。

## 実装と確認

- 経路の−1/0/+1を浮動小数点から整数へ変換する処理を、比較マスクと小さな参照表へ置き換えました。
- 同点時に元の候補を保持するオペランド順で倍精度の最小値命令を使い、独立した4組の計算を展開しました。
- AVX2と通常DPの照合を強化し、符号付きゼロ、極小値、大きな有限値、不規則な指数、各幅の端数を含めてコストのビット列と経路が一致することを確認しました。
- `cargo fmt --all -- --check`、`cargo clippy -p seam_scale --all-targets -- -D warnings`、`cargo test -p seam_scale`、releaseビルドは成功。通常テスト21件成功、計測専用2件は通常実行から除外しています。
- PiPLの埋め込みと生成バイト列の一致テストも成功しています。
