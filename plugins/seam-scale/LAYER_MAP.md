# 入力マップによる拡縮（v0.3.0）

独立版SeamMapの機能をSeamScaleへ統合し、黒・白の倍率指定から「アンカーの明るさからの距離」に対応するMin/Maxへ変更しました。旧独立版は既存プロジェクトの互換性のために残します。

## 操作と表示

| Use Map Layer | Separate X/Y Scale | 表示する倍率 |
|---|---|---|
| OFF | OFF | Scale |
| OFF | ON | Scale X / Y |
| ON | OFF | Min Scale / Max Scale |
| ON | ON | Min/Max Scale X / Y |

入力レイヤー、Map Channel、Anchor、ToleranceもマップONの間だけ表示します。OFFでは通常のシーム処理へ戻り、マップのチェックアウトや計算を行いません。隠したパラメーターの値とキーフレームは保持します。

制御レイヤーは変形対象と同じピクセル座標で参照します。位置・サイズ・エフェクトを含めた調整が必要なら、変形対象と同じサイズへプリコンポーズしてください。制御レイヤーの表示はOFFにできます。レイヤー未指定なら入力画像をそのまま返します。

Map ChannelのLightnessは `0.2126 R + 0.7152 G + 0.0722 B` です。各成分は0〜1へ制限し、透明部分はAEからの乗算済みRGBを使います。Seam Channelは別の項目で、シームを選ぶための画像側のエネルギーを決めます。

## 倍率とアンカー

明るさ `m` とアンカー `a` を0〜1で表したとき、正規化距離と指定倍率を次のように求めます。

```
d = |m - a| / max(a, 1 - a)
scale = Min + (Max - Min) * d
```

| 明るさ | アンカー50%、Min50%、Max150%での指定倍率 |
|---|---|
| 0% / 100% | 150% |
| 25% / 75% | 100% |
| 50% | 50%（位置はアンカーとして固定） |

アンカー30%なら0%と60%が同じ倍率です。最も遠い100%がMaxになります。MinとMaxは距離の両端を表す名称であり、MinをMaxより大きくして逆向きに補間しても構いません。負の倍率では絶対値でシームを計算し、その軸の参照を反転します。

アンカーは指定倍率を100%へ変更するのではなく、参照座標を補正して元の位置へ固定します。Toleranceの範囲内は元の画素をそのまま保持します。既定±0.2%は8bitの中間グレーの量子化差を吸収します。

## 変形と制約

- 倍精度の逐次DPで必要なサイズのシームを正確に計算します。複数サイズの問い合わせでは同じシーム計算を共有します。
- X→Yの順に処理します。各軸で元キャンバスへ中央配置、またはRestore Original Sizeによる通常のリサイズを行った参照座標を作ります。
- 元マップ上のアンカー画素・明るさがアンカー値をまたぐ位置を固定点にします。行内で位置の補正量を線形補間し、固定点の外側は最寄りの補正量を使います。固定点がない行には補正を加えません。
- 補正後の座標から入力画像を補間します。キャンバス外は透明です。入力マップ自体は変形しません。

固定点と任意の局所倍率を同時に厳密に満たせるとは限りません。複数固定点の間では補正により実効的な局所倍率が変わります。全画素がアンカー範囲内なら入力と同じ画像になります。急なマップ変化・強い倍率では不連続や折り返しが生じる場合があります。

入力マップモードはDPの参照座標に位置補正を加えるため、通常のSeamScaleで画素を削除・挿入した画像とは補間部分の見た目が異なります。高速化のためにシームを近似する方式ではありません。高解像度・広い倍率範囲は処理負荷が大きくなります。

既存の`Output: Seam Map (Displacement)`はマップOFFで利用できます。入力マップONではOutput項目を隠して画像を出力します。旧プロジェクトのパラメーターIDは維持しています。
