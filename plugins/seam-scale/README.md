# AOD_SeamScale

画像内容に応じてシームを削除・挿入する、After Effects用のスケーリングエフェクトです。Windowsの出力ファイルは `AOD_SeamScale.aex`、Match Nameは `SeamScale` です。

## パラメーター

| 項目 | 動作 |
| --- | --- |
| Separate X/Y Scale | OFF: 共通倍率。ON: X/Yを個別指定。使用しない倍率は非表示になります。 |
| Scale (%) | 共通倍率。既定100%、入力範囲−400〜400%。負の値は上下左右を反転します。 |
| Scale X (%) / Scale Y (%) | 個別倍率。それぞれ既定100%、入力範囲−400〜400%。Xの負値は左右、Yの負値は上下を反転します。 |
| Restore Original Size | シーム処理後に通常のバイリニア補間で元の幅・高さへ戻します。既定OFF。 |
| Seam Channel | シーム判定に使うチャンネル。RGB / RGBA / R / G / B / A / Lightness。既定RGBAで、旧版の見た目を維持します。 |
| Output | Image / Seam Map (Displacement)。既定Image。マップはR＝横の参照変位、G＝縦の参照変位、B＝有効領域、A＝不透明です。 |
| Use Map Layer | 既定OFF。ONにすると通常のScaleとOutputを隠し、入力マップとMin/Maxの設定を表示します。 |
| Scale Map Layer / Map Channel | 制御用レイヤーと参照成分（Lightness / R / G / B / A）。未指定なら入力画像をそのまま返します。 |
| Min Scale / Max Scale | アンカーからの明るさの距離に対応する倍率。距離0がMin、最も遠い黒または白がMax。各−400〜400%。 |
| Min/Max Scale X / Y | Separate X/Y ScaleがONのときだけ表示する軸別のMin/Max。 |
| Anchor Map Value (%) | 固定する明るさ。既定50%。この値から同じ距離の明るさには同じ倍率を割り当てます。 |
| Anchor Tolerance (+/- %) | 固定する明るさの許容幅。既定±0.2%。 |

処理は常にX→Yの順です。共通倍率と同じ値をX/Yに指定した場合、同じ結果になります。

### 入力マップによる拡縮（v0.3.0）

`Use Map Layer`をONにし、`Scale Map Layer`へ制御用レイヤーを指定します。マップの明るさとアンカーの**絶対差**からMin〜Maxを補間し、アンカーの位置を固定します。アンカー50%なら黒と白は同じMax、25%と75%は同じ中間倍率になります。

通常のScale、共通Min/Max、X/Y別Min/Maxの値は独立して保持します。チェックボックスを切り替えても値やキーフレームは変更しません。入力マップONでは画像を出力し、旧`Output`の値はOFFへ戻した際に復帰します。

距離の正規化、固定点の補正、素材の準備方法は[入力マップの仕様と検証](LAYER_MAP.md)を参照してください。旧独立版`AOD_SeamMap`は既存プロジェクト用に残し、新規利用には本機能を使います。

倍率の絶対値が100%未満なら縮小、100%を超えると最大400%まで拡大します。負の倍率では、絶対値でシームを計算した後に該当軸を反転するため、正の倍率の結果をそのまま裏返せます。例: X=−150%、Y=100%は横方向に1.5倍へ拡大して左右反転します。0%を含め、丸め後の各辺は最小1pxです。

元サイズへの復元がOFFの場合、処理後の画像を元のレイヤーキャンバスの中央へ画素単位で配置します。縮小時の余白は透明、拡大時にはキャンバス外が切れます。レイヤーやコンポジションの寸法自体は変更しません。幅・高さは倍率の絶対値から四捨五入します。

### チャンネルの意味

選択するのはシームの重要度を判定する成分です。画素の移動・削除・挿入はRGBA全体で行います。Rを選んでも、赤チャンネルだけが別の位置へ移動するわけではありません。

| 選択 | 判定する成分 |
| --- | --- |
| RGB | R、G、Bそれぞれの縦横の変化量を加算します。 |
| RGBA | Lightnessの変化量とアルファの変化量を加算します。Lightness + Alphaをこの項目へ統合した、旧版と同じ計算です。 |
| R / G / B / A | 選択した1成分の変化量を使います。 |
| Lightness | 作業RGBの加重輝度 `0.2126R + 0.7152G + 0.0722B` の変化量を使います。 |

パラメーターは既存項目の末尾へ追加し、既存の倍率・チェックボックスのIDを維持しています。

### Seam Map出力

v0.2.0では、同じシームに沿って元画像の座標を追跡するマップを出力できます。AE標準のディスプレイスメントマップに、横＝Red・最大変位＝元の幅、縦＝Green・最大変位＝元の高さとして接続します。32bpcでの使用を推奨します。マップのプリコンポーズ、余白のマット設定、補間による直接出力との差は[Seam Mapの使い方と検証](SEAM_MAP.md)を参照してください。

## シーム計算と画質

- 各シームを倍精度の動的計画法で求めます。縦シームの各行は、前行の左・中央・右の3候補から最小累積コストを選びます。同点時には左側を優先します。
- エネルギーは、選択した成分の縦横中心差分の絶対値和です。AEの作業色空間にあるプリマルチRGBを使用し、画像端は端の値で延長します。アルファは0〜1へ制限し、アルファ0の隠れたRGBはエネルギーに寄与しません。
- 通常モードでは縮小時の残存画素を補間しません。拡大時は、作業画像からシームを1本ずつ除去して元の画素位置を記録し、元画像へ異なるシームを挿入します。挿入画素は隣接画素の平均です。大幅な拡大は段階的に処理します。入力マップモードは同じ逐次DPから参照座標を求め、固定点の位置を補正して画像を補間します。
- 8/16/32bpc、Smart Render、Multi-Frame Renderingに対応する実装です。32bpcのRGBは0〜1へクランプしません。8/16bpc出力は丸め処理を用います。
- ピクセル数の間引き、複数シームの近似的な同時選択、前フレームのシーム流用は行いません。エネルギーや処理順によって見た目は変わるため、他社のContent-Aware Scaleとの同一出力を保証するものではありません。

方式の参考: [Avidan / Shamir, Seam Carving for Content-Aware Image Resizing (2007)](https://www.merl.com/publications/TR2007-087)。実装コードは本プラグイン用です。

## 高速化

- x86-64ではAVX2を実行時に検出し、4画素分の倍精度DPを同時に計算します。非対応CPUでは通常実装へフォールバックします。加算順序・精度・同点の扱いは同じです。
- v0.1.4では、経路の記録を比較マスクから直接生成し、独立した4組のDP計算を展開します。同じCPU・1080p・50%のCLI比較で、グラデーション・図形・ノイズの処理時間を約30〜39%短縮しました。全比較の出力画素はv0.1.3と完全一致しています。条件と制約は[性能検証記録](PERFORMANCE.md)を参照してください。
- v0.1.5では、シームを削除するときに左右の短い側だけを移動し、行の先頭位置を調整します。画素の並びやDPの計算は変わりません。AE 2025の4K・50%の合成動画で、PNG書き出し込みの平均をv0.1.4の6.54秒から5.30秒へ短縮しました。素材による差やCLI比較は[4K性能検証記録](PERFORMANCE_4K.md)を参照してください。
- エネルギーはシーム除去で影響する近傍だけを再計算します。画素特徴は固定し、必要なインデックスだけを移動します。
- 縮小では、画素間の接続とDP結果を保持し、変化が伝わった範囲だけ更新します。影響範囲が広い画像は連続メモリ上の全体DPへ切り替えます。切替は性能上の判断であり、シームの解は変わりません。
- フレーム間で共有する可変キャッシュは使いません。動画は毎フレーム計算するため、大きな解像度・変更量では時間がかかります。GPU実装はありません。
- 入力・中間・出力画像は各辺32768px以内、合計33554432画素以内です。必要メモリを確保できない場合は明示的にエラーにします。処理中の中断要求にも対応します。

## ビルド・検証

worktreeルートで実行します。次のコマンドはAEへのインストールや起動を行いません。

```powershell
cargo fmt --all -- --check
cargo clippy -p seam_scale --all-targets -- -D warnings
cargo test -p seam_scale
cargo build -p seam_scale --release
Copy-Item -LiteralPath target/release/seam_scale.dll -Destination target/release/AOD_SeamScale.aex
```

CLIの性能計測:

```powershell
cargo test -p seam_scale --release benchmark_video_1080 -- --ignored --nocapture
```

全経路探索、全体DPとのシーム・画素一致、AVX2一致、局所エネルギー更新、DP再利用からの切替、全7チャンネルでの縮小・400%までの拡大・拡縮混在、負の倍率に用いる軸反転、HDR・透過、元サイズ復元、サイズ制限、中断を自動テストで検証します。

`tests/ae_smoke_test.jsx` と `tests/verify_ae_smoke.py` はAE実機確認用です。空の検証用プロジェクトでJSXを実行し、PNGの書き出し完了後に`python plugins/seam-scale/tests/verify_ae_smoke.py target/seam-scale-ae-0.2.0`で比較します。`tests/ae_benchmark.jsx`は、そのテストプロジェクトで1080p・50%の合成動画を3フレーム、レンダーキューからPNGへ出力して計測します。PNG出力モジュールのテンプレートが必要です。MCP経由では、実行前に`$.global.AOD_SEAM_TEST_ROOT`へworktreeルートの絶対パスを設定してください。

`tests/ae_benchmark_4k.jsx`は保存済みの検証プロジェクトで4Kの3フレームを計測します。実行設定と旧版との照合手順は[4K性能検証記録](PERFORMANCE_4K.md)に記載しています。

v0.1.3は、ユーザーの許可のもとでAE 2025の描画156ケースとUIを確認し、配置とカタログ画像を更新済みです。WindowsのPiPLはバイナリのまま埋め込み、旧方式の文字コード変換による起動時エラー（25::31）を修正しています。埋め込んだPiPLと生成バイト列の完全一致もテストします。詳しい条件と結果は[検証記録](VALIDATION.md)を参照してください。

v0.1.5では、描画テスト156枚、1080p動画3枚、4K動画3枚の計162枚がv0.1.4と完全一致しました。条件・未確認範囲は[4K性能検証記録](PERFORMANCE_4K.md)、v0.1.4の結果は[前回の性能検証記録](PERFORMANCE.md)を参照してください。

v0.2.0はSeam Map出力を追加しました。通常のImage出力156枚はv0.1.5と完全一致し、自動テスト26件も成功しました。マップは8/16/32bpcの27ケースをAE標準エフェクトへ接続して検証しています。詳細と再現手順は[Seam Map検証記録](SEAM_MAP.md)を参照してください。

v0.3.0は入力マップ、アンカーからの絶対距離による倍率、動的な項目の表示切り替えを追加します。[入力マップの仕様と検証](LAYER_MAP.md)を参照してください。

AEの起動・終了・操作、プラグインの配置更新、実機検証はユーザーの事前確認後に行います。既に許可された検証の範囲では、その許可に従って進めます。
