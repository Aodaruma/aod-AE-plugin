# color-boundary-blur ( AOD_ColorBoundaryBlur )

Blurs boundaries where selected colors meet using isotropic or boundary-normal kernels.

This is the After Effects plugin **AOD_ColorBoundaryBlur**, which provides the **ColorBoundaryBlur.aex** plugin file for Adobe After Effects.

## Parameters

- `Color Tolerance` and `Minimum Alpha` control which pixels match each selected color.
- `Color Proximity` bridges short anti-aliased gaps between two selected color regions.
- `Number of Colors`, `Add/Remove Color`, and the dynamic `Color` controls manage 2–16 colors.
- `Blur Mode` selects Box, Gaussian, or boundary-normal anisotropic blur.
- `Blur Radius`, `Normal Samples`, and `Along-Boundary Radius` control the blur kernel.
- `Post Smooth`, `Boundary Width`, and `Mask Feather` soften the result and its transition.
- `Mix`, `Edge Mode`, and `Preserve Alpha` control compositing and image-edge behavior.
